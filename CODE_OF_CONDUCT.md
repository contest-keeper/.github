# Code of conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good intent and keep discussions about the work.

To report unacceptable behaviour, contact the maintainers privately on GitHub
([robbertpopa](https://github.com/robbertpopa)). Reports are kept confidential.
