Contest Keeper helps contest organizers check that submissions are genuine: written by the contestant, without AI.

- [ck-os](https://github.com/contest-keeper/ck-os) - bootable system for contest machines
- [ck-forge](https://github.com/contest-keeper/ck-forge) - prepares the USB sticks
- [ck-hub](https://github.com/contest-keeper/ck-hub) - server and dashboard
- [ck-hub-setup](https://github.com/contest-keeper/ck-hub-setup) - Docker setup for the hub
- [ck-protocol](https://github.com/contest-keeper/ck-protocol) - shared code
- [ck-website](https://github.com/contest-keeper/ck-website) - website and docs

Work in progress.
